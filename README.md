# ha-wine – Vinkælder til Home Assistant

App (add-on) til Home Assistant med vindatabase: lager, søgning, sortering efter drikkevindue,
auto-estimat af drikkevindue, statistik og import fra den gamle Excel-vindatabase.

## Installation

1. Gå til Indstillinger → Apps → App-butik → ⋮ → **Repositories**.
2. Tilføj `https://github.com/taugusti/ha-wine`.
3. Installér **Vinkælder**, start den og slå **Vis i sidebjælke** til.

Se [vinkaelder/DOCS.md](vinkaelder/DOCS.md) for brug, import og sensorer.
